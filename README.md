# Projek-Lunas-PPL
Pengembangan LUNAS (Laundry Order &amp; Administration System), sebuah sistem informasi manajemen laundry berbasis web untuk membantu pengelolaan pesanan, pembayaran, pemantauan status cucian, dan laporan transaksi secara lebih terstruktur. Dikembangkan sebagai proyek kelompok menggunakan Vue.js dan Vite.
